# Quick Fix

Raycast extension (TypeScript) that fixes spelling and grammar on selected text using the user's own API key.

## Conventions

- Branch names: `ft/<short-kebab-description>` (for example `ft/cursor-backend`). Branch from `origin/main` with `--no-track`.
- Plans live in `docs/` (for example `docs/plan-cursor-backend.md`).
- Lint with `npm run lint`. It currently fails on the `author` field in `package.json` until a real Raycast username is set.
